| Field | Type | Required | Default |
| --- | --- | --- | --- |
| `id` | `string` | Yes | — |
| `name` | `string` | Yes | — |

| `schemaVersion` | `number` | No | `1` |
| `version` | `string` | No | `"0.0.0"` |
| `updatedAt` | `string` | No | `new Date().toISOString()` |
| `questions` | `Question[]` | Yes | — |

A pack `id` must match `/^[a-zA-Z0-9_-]+$/`, and it can't be any of these: `__proto__`, `constructor`, `prototype`.

## Limits

| Limit | Value |
| --- | --- |
| Largest pack file, in bytes | 5,242,880 (5 MB) |
| Fewest `choices` | 2 |
| Most `choices` | 6 |
| Most questions in a pack | 1,500 |
| Longest value for any other text field | 2,048 |
| Longest `prompt` | 5,000 |
| Longest pack or question `id` | 100 |
| Highest `schemaVersion` | 1,000 |
